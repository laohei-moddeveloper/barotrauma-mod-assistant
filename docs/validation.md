更新验证覆盖并行调度、独立失败、取消、版本变化、路径边界、缓存复用、备份与崩溃恢复。0.2.0 起覆盖启用切换和资源/源代码重叠分析。0.3.0 额外覆盖顺序保存、循环依赖、重复定义优先级、LuaCs 版本和哈希错误、安装失败和中断恢复。

0.3.0 用官方真实 Windows 客户端补丁，在隔离游戏目录安装、逐一检查 57 个文件、确认永久 C# 配置、重复安装跳过并恢复原文件，文件指纹完全一致。补丁游戏版本为 1.13.4.0，压缩包 SHA-256 为 `47ceee04b0139e1d7115d32a43c632d7601aa51c5ae17d7c0d8bbc9655c528af`。该验证没有覆盖真实游戏。

排序窗口在实际启用列表上验证了拖动、上下移动和自动排序预览；真实配置保持不变。界面和打包后的实际加载顺序读取已检查。

此前 0.1.0 对当时 31 项完整工坊缓存完成了真实联网请求与安装；当时没有待下载的新版本，因此不代表真实下载吞吐量比较。尚未以助手安装后的 LuaCs 进行游戏内实测，静态兼容和排序结果也不保证联机兼容。

发布包中的 `release-manifest.json` 记录程序、压缩包和主要源码的 SHA-256；`SHA256SUMS.txt` 可校验下载包。源码和程序不包含个人配置、原始日志或游戏文件。

0.4.0 增加多套配置的一次写入、游戏启动/并发配置改动保护、跨电脑本地模组唯一名称匹配、保留其他游戏设置和旧清单导入。分析缓存验证复用、脚本/资料变化失效，以及轻量模式无资源遍历/源码读取；普通重复定义与 XML Override 的预期优先项及文件证据均覆盖。

整套快照验证独立副本、文件修改后的恢复、保持当前音量设置、游戏版本/损坏内容拒绝、空间不足、恢复目录或配置提交后失败回滚，以及模拟崩溃后下次操作恢复。尚未对真实模组执行整套还原，以隔离目录验证文件与配置安全性。

联机配齐验证缺失项订阅/下载后整体应用、失败保留启用配置、默认拒绝版本差异、明确允许差异、本地缺失阻止联网。订阅接口用模拟确认成功/失败/取消/超时；公共资料的所属游戏检查用模拟响应及官方 LuaCs 工坊项目的真实只读查询验证。实际接口符号在本机游戏 DLL 中检查，但未自动订阅用户账号的新项目，也未完成真实朋友联机实测。

新版源程序和主界面在真实游戏运行期间完成只读检测：51 个模组，24 个启用，51 个深度分析全部延后。游戏关闭后完成全部模组的实际资源分析；发布 EXE 在游戏关闭时完成自检并验证缓存复用。拖动和自动排序仅预览，实际启用配置未修改。日志诊断验证片段读取、敏感字段遮盖和大文件 UTF-16 尾部解码；LuaCs 验证指引明确不宣称游戏内脚本已通过。

0.5.0 使用隔离助手设置，加载本机 51 项清单及已有分析缓存检查主页面、工具/设置页、三种主题、加载顺序/管理窗口和 1000×680、12 号字紧凑布局。界面预览没有连接 Steam，游戏配置前后字节相同；本次换肤测得约 17–25 毫秒，仅代表该环境的界面操作。独立程序自检另外确认三页导航、三个主题与已有窗口颜色、关键列不隐藏，并沿用模组分析及加载顺序检查。

新增测试覆盖无效外观字段回退、自选强调色按钮/强调文字至少 4.5 对比度、预设正文文字对比度、换肤不丢失选中项/任务对象、不修改游戏配置、日志折叠保留内容、可选列、偏好序列化与默认恢复保留运行参数、筛选/搜索及大字号下主要按钮和列表空间。界面检查不代表新的下载性能、LuaCs 游戏内运行或联机兼容验证。
