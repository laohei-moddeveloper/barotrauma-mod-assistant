# v0.6.1 — 新用户体验、速度与稳定性 / First use, speed & reliability

Download `BarotraumaModAssistant-v0.6.1-win64.zip`, extract it, and run `BarotraumaModAssistant.exe`. Use the Chinese/English selector at the top. Python is not required. The same version is available on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3812360206).

- 新增「首次使用与环境检查」及「LuaCs 恢复说明」。无备份、已恢复、文件缺失或记录损坏时禁用恢复；说明完整安装备份与仅设置备份的区别。
- 游戏搬盘后重新定位；首次启动尚未生成配置、空模组列表、Steam 接口问题提供处理步骤。无效运行参数安全回退，损坏设置另存；偏好不可写时保留会话操作并显示无法保存。
- 仅刷新变化的列表行，翻译采用有限缓存，扫描减少对图片等无关文件的检查；资料查询失败保留已有缓存并退避，缓存无法写入仍可使用当前分析。恢复时重检游戏是否启动并响应停止。

**Getting started & environment** is in Settings; **LuaCs restore help** is in Tools. An existing working LuaCs installation may have no assistant backup and needs no action. Settings-only restore does not uninstall LuaCs. Restore help explains Steam verification and automatic-install launch options. Missing or invalid backups are identified before any restore task starts.

The assistant recovers from invalid preferences, moved game paths, and temporary public-metadata failures. Unwritable caches do not discard the current analysis. Progress updates redraw changed rows, repeated translations use bounded caching, and scans avoid unnecessary texture checks while retaining resource/code change detection. These changes do not bypass Steam download scheduling or bandwidth limits.

Validation: **123 tests passed**, including isolated fresh-install layouts, Chinese/space paths, malformed preferences, permissions, missing/settings/full/damaged/restored backups, network failures/recovery, cancellation, and unchanged-row rendering. The packaged executable passed Chinese/English and three-theme checks. UI previews use fictional mods; game configuration was unchanged.

Synthetic benchmark on the development machine: a 500-row list with one changed row took a median **11.43 → 3.87 ms**; a folder with 2,000 textures and 20 scripts took **67.92 → 30.92 ms** to check, producing the same signature. These timings measure local UI/file checks, not real Workshop download throughput or every user's hardware. They do not certify all mod combinations or in-game multiplayer compatibility.

After updating Workshop files, close the assistant and rerun the desktop installer to update a separate desktop copy. Existing preferences are retained. ZIP includes Chinese and English guides. `release-manifest.json` and `SHA256SUMS.txt` provide file verification. Previous versions and tags are retained.
