# BaroDock 1.0 — 自动排序与具体排错

让模组准备、查错和恢复变成可审核的操作流程。独立 Windows 64 位程序，中文 / English，无需 Python。

- 自动排序先显示前后变化和依据；拖动、撤销、锁定和明确规则一起使用，审核后再应用。
- 排序依据可绑定实际文件及核心/脚本环境；同版本文件更新也能识别，暂停过期依据。
- Item 对照解释整份 Override、继承、Clear、注册错误和丢失字段，显示相关资源与引用。未审阅类型不套用同一加载规则。
- 保存现场与复现步骤，生成原生修复草稿，再检查新的日志；追加日志核对旧字节前缀，重复异常按完整调用块归并。
- 明确选择字段可导出独立兼容草稿；反向依赖查询、本地标记和双语界面帮助整理大清单。
- 可选只读 Lua 模块已在真实 LuaCs 客户端试玩回合验证，包顺序和所查询物品数据可成功导入；修复真实环境的小数时间戳兼容问题。
- 补齐分析取消响应、观察对照的轻量读取，以及桌面安装后的指南路径。

保持有限访问与用户审核；没有新增生产依赖、进程扫描、账号管理、自动订阅、管理员提权或遥测。游戏内观察是具体会话证据，不是所有脚本、构造行为或模组组合的安全/兼容认证。

新操作流程见 [排查指南](../docs/investigation-workflows.md)，验证边界见 [验证说明](../docs/validation.md)。

## English

BaroDock 1.0 brings reviewable sorting, updates, presets and specific troubleshooting into one standalone Windows app.

Review proposed order changes and reasons before applying. Bind rule evidence to actual files, inspect Item inheritance and lost changes, save an investigation scene, export a repair or companion draft, and recheck a new log. Reverse dependency queries and local labels help organize larger lists.

The optional read-only Lua observer was tested in a real LuaCs client test round. Loaded packages and selected Item fields imported successfully; fractional timestamps were corrected. Cancellation, lightweight observation comparison and installed guide links were also improved.

No new production dependency, process scan, account manager, automatic subscriptions, elevation request or telemetry. Supported checks are scoped evidence, not universal runtime compatibility or malware certification.
