# v0.6.0 — 中文 / English

中文与英文现在可以在程序右上角实时切换并自动保存。按钮、菜单、筛选、排序/规则、配置/联机/快照、LuaCs、兼容分析、日志说明和错误提示均提供英文；已打开窗口和报告同步更新。切换不改变模组名称、编号、路径、实际启用状态、排序预览或运行中的任务。英文列宽和长按钮适配小窗口，恢复默认外观保留语言偏好。

Download `BarotraumaModAssistant-v0.6.0-win64.zip`, extract it, and run `BarotraumaModAssistant.exe`. No Python installation is needed. Use the **中文 / English** selector at the top; your language is remembered. English and Chinese guides are included. Mod names, IDs, paths, and original third-party log excerpts retain their original language.

The same version is distributed through [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3812360206). After a Workshop update, close the assistant and rerun the desktop installer or replace your separate executable copy. `Install-to-desktop.cmd` provides English installation messages and a shortcut. Existing preferences are retained.
