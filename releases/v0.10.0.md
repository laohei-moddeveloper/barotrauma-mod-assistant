# BaroDock 0.10.0

Ordering evidence, campaign matching and concrete conflict investigation / 排序依据、存档关联与具体排查。

- Record rule reasons, sources, dates and exact installed-version scopes. Suspend stale/unreadable scopes. Correct the old assumption that a cross-mod directory reference implies activation or loading precedence; own Workshop-ID macros are supported.
- Import a selected campaign save, confirm missing/ambiguous names, preview the core/order and export a normal game ModLists XML without altering the save or enabled list.
- Compare exact XML fields, Vanilla values and provider files. The scoped 1.13.4.0 Item registration model identifies ordinary duplicate registration and whole-definition Override selection. Clear, inheritance, unreviewed types/versions and scripts are not guessed.
- Link explicit logged duplicate errors to current identifiers/files with repair and reproduction steps. Path mentions are not sole-cause attribution; an extra Override does not remove two ordinary registrations.
- Separate C# allow/disable/prompt/unreadable policies and file traces from session execution. Retain existing access limits and the six-action manager layout.

234 local unit/isolated checks, packaged bilingual fixture workflows and read-only inspection of 53 local mods passed. Existing game configuration stayed unchanged. No new runtime dependency. Real gameplay, all mod combinations and malware detection are not certified.
