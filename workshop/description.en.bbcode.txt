[h1]BaroDock | Barotrauma Mod Manager[/h1]
Update mods, organise load order and save setups. Chinese / English UI, sorting explanations, static compatibility warnings and optional LuaCs / C# installation.

[b]Windows 64-bit standalone tool. No Python or LuaCs required for BaroDock itself. Run a separate copy; do not enable this package in-game or require it on a server.[/b]
[b]Start here:[/b] Subscribe → wait for download → run Install-to-desktop.cmd → close the game and open BaroDock. Folder paths are in Getting started below; GitHub downloads are above.
[b]Access at a glance:[/b] local file inspection by default. You confirm online actions and LuaCs installation. No system-wide process enumeration, telemetry or administrator elevation request. [url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]Access purposes and limitations[/url]

[h1]0.7.0: changes following community feedback[/h1]
The earlier process checks were broader than necessary. This version removes system-wide process enumeration and automatic subscription calls. Startup and Refresh now inspect local files. Online actions and LuaCs installation explain access before you proceed. Thank you to the players who raised these concerns.

[b]Access scope:[/b] read the selected game folder, the current user's game/mod configuration, and Steam installation/Workshop manifests. File protection checks only the selected game's two executable files, without reading other process names or memory. No wallet, browser-credential or firewall inspection; no telemetry or automatic log/report uploads; no administrator elevation request.

Online inspection/update uses the game's official Steam interface for Barotrauma and sends item IDs to Steam for public metadata. Steam may show the game as running while connected. LuaCs installation downloads an official GitHub patch and changes backed-up client files/C# settings only after confirmation. [b]This ordinary desktop application is not an OS sandbox and cannot isolate Steam, LuaCs or third-party mods.[/b]
[url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]Full access explanation, native-interface reasons and limitations[/url] are also included in the download and in Settings > Access & privacy.

[h1]Getting started[/h1]
[olist]
[*]Subscribe and wait for Steam to finish. If necessary, open Barotrauma to the main menu to install Workshop files, then exit.
[*]Press Win+R and open:
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\__WORKSHOP_ID__[/code]
[*]Run [b]Install-to-desktop.cmd[/b] to create a BaroDock shortcut, or copy BarotraumaModAssistant.exe into your own folder and run it there. No separate runtime needed.
[/olist]
If that folder is missing, use Steam > Barotrauma > Manage > Browse local files, go up to steamapps, then open [code]workshop\content\602960\__WORKSHOP_ID__[/code] in the library where the item downloaded.
The desktop copy is stored in [code]%LOCALAPPDATA%\BarotraumaModAssistant\WorkshopProgram[/code]
[b]After an update:[/b] close the old assistant and re-run the installer, or replace your copied executable. Steam does not automatically replace your separate desktop copy. Existing settings and program filenames are retained for upgrades. Unsubscribing does not delete your copy/settings.

[h1]Everyday use[/h1]
[olist]
[*]Close the game/server before changing files, enabled mods, profiles, order or LuaCs. Startup is local; choose [b]Online inspection[/b] for current Steam status/public metadata. Online actions need Steam signed in.
[*][b]Update[/b] selects a mod for the task; [b]Enabled[/b] controls whether the game loads it. Click [b]Update mods[/b] to request downloads for subscribed items.
[*]Open [b]Load order[/b]: auto-sort, drag or move rows, inspect [b]Sorting reasons[/b], then [b]Apply draft[/b]. Import/export local JSON rules and locks; importing does not change game order.
[*]Use profiles to save/switch setups or compare a friend's list. Subscribe to missing items manually in Steam before [b]Download and apply[/b]. Local mods must be installed separately.
[*]LuaCs, snapshots, logs and reports are in Tools & scripts. Choose English/Chinese at the top; themes, fonts, columns and update settings are in Settings & appearance.
[/olist]

[h1]Features and practical limits[/h1]
[list]
[*][b]Parallel requests/installations:[/b] reuse verified cache, retry failures and keep backups. Steam controls actual network scheduling; this cannot bypass its queue, server limits or bandwidth. Accepted downloads may continue after stopping the assistant.
[*][b]Explainable sorting:[/b] resource dependencies and explicit rules, preserving existing overlapping-definition order where possible. No category/name guesses. Inspired by RimPy's workflow; Barotrauma authors' instructions take priority.
[*][b]Static compatibility warnings:[/b] compare XML identifiers/overrides, readable Lua hooks and C# patches; show relevant files and possible overlap. Cannot prove runtime compatibility or repair mod code. Impact means scope, not quality.
[*][b]LuaCs + C#:[/b] official matching Windows client patch, verification, backups and restoration of files saved by this assistant. Existing installations may have no backup; settings-only restoration does not uninstall LuaCs. Other clients/servers need separate setup. Use trusted script mods; file checks are not gameplay tests.
[*][b]Profiles/snapshots:[/b] keep enabled lists/order and backed-up mod files. Steam provides current versions, not historical versions from shared lists. Fingerprint/version mismatches block applying profiles by default. Snapshots consume space and do not restore subscriptions or the LuaCs patch.
[*][b]Local inspection:[/b] reuse caches and defer deep scanning when selected game files are busy or their state is unknown. Cannot identify the holder or check another installation. Close the game and Refresh for current results.
[*][b]Bilingual personalisation:[/b] Chinese/English, three themes, accent colors, fonts, density, search/filtering, selectable columns and remembered window layout. Mod names, paths and original logs keep their own language.
[/list]
