[h1]Review the order. Investigate the evidence.[/h1]
BaroDock 1.0 is a free standalone Windows 64-bit Barotrauma mod manager. Organize load order, update mods, keep presets and investigate specific XML or log issues. Switch between English and Chinese. Python is not required.
[b]This Workshop item delivers an external tool. Install it to your desktop; do not enable it as a gameplay mod or require it on your server.[/b]

[h1]What it helps with[/h1]
[list]
[*][b]Auto-sort and dragging:[/b] use author declarations, explicit rules and locks. Review proposed changes and reasons before applying. Undo is available; names such as “Patch” do not invent mandatory order rules.
[*][b]Specific diagnostics:[/b] compare XML identifiers, fields and source files. Reviewed Item checks explain inheritance, Clear, registration problems and lost changes. Logs keep early failures and group complete exception blocks.
[*][b]Recheck after updates:[/b] record rule sources, versions and actual file hashes. Changed bytes can suspend old evidence even when the declared version stays the same.
[*][b]Repair and recheck:[/b] save inputs and reproduction steps, create native repair presets or explicit field drafts, then check a new test log. An optional read-only Lua observer compares loaded packages and selected Item fields.
[*][b]Lists and recovery:[/b] native ModLists, read-only campaign matching, snapshots, scoped restores, reverse dependency queries and local labels. Presets, saves, snapshots and LuaCs backups have separate purposes.
[*][b]Updates and scripting tools:[/b] concurrent requests/install scheduling and failed-item retry. Official LuaCs client installation/update is separate from C# permission; updating does not enable C# by default.
[/list]

[h1]Install and get started[/h1]
[olist]
[*]Subscribe and wait for Steam to download. If the installed folder is missing, open Barotrauma to the main menu, then exit.
[*]Press Win+R and open:
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\__WORKSHOP_ID__[/code]
[*]Run Install-to-desktop.cmd, or copy BarotraumaModAssistant.exe to your own folder and run it.
[/olist]
Alternatively check the Steam library containing the game:
[code]steamapps\workshop\content\602960\__WORKSHOP_ID__[/code]
The desktop copy is in [code]%LOCALAPPDATA%\BarotraumaModAssistant\WorkshopProgram[/code]
[b]After a Workshop update, close the old app and rerun the installer or replace the desktop copy.[/b] Steam does not update that separate copy. Your preferences are retained.

[h1]Everyday use[/h1]
Close the game and dedicated server before file or list changes. Update selection and Enabled state are separate. Start with Auto-sort preview, then review changes. Select a mod and open Full analysis → XML override comparison for specific definitions. Log diagnosis contains scene records, repair drafts and rechecks. Subscribe to missing Workshop items manually in Steam; install local packages separately.

[h1]Clear limits[/h1]
Steam controls download queues and bandwidth; this app cannot promise to bypass them. File evidence and models do not certify all scripts, constructors, mod safety or universal compatibility. Unsupported content types do not inherit Item conclusions. Drafts need review and a separate test session; historical mod versions cannot be reconstructed from data a save never recorded.

The 1.0 optional observer passed a real LuaCs client test round on this machine: package order and queried Item data imported correctly, and fractional timestamp handling was fixed. Other computers and complete multiplayer combinations still need testing. See [url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/docs/validation.md]verification scope[/url].

[b]Access:[/b] selected game files, the current user's game data, Steam game manifests and assistant data. Online and write actions are explicit. No process enumeration/memory reads, automatic subscriptions, wallet/credential/firewall inspection, telemetry or elevation request. C# mods and normal desktop apps are not OS sandboxes. Review personal information in logs and reproduction notes before sharing. [url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]Access details[/url]

[h1]Feedback is welcome[/h1]
Thank you for testing, writing detailed reports and sharing screenshots. Practical usability matters more than feature counts. If an action is hard to find, a warning is unclear, or sorting/recovery does not help, please tell me in comments or [url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/issues]GitHub Issues[/url]. Include the version, steps and exact error; avoid passwords, codes or unreviewed full logs. I will investigate, document corrections and keep learning from your suggestions.
