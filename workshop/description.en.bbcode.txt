[h1]Spend less time organizing mods[/h1]
BaroDock is a free, standalone Windows 64-bit Barotrauma mod manager: load-order previews and dragging, updates, game presets, backups and XML override comparisons. No Python installation needed. Switch between English and Chinese in the app.
[b]This Workshop item delivers an external tool. Install it to your desktop; do not enable it as a gameplay mod or require it on your server.[/b]

[h1]Install and get started[/h1]
[olist]
[*]Subscribe and wait for Steam to download. If the installed folder has not been created, open Barotrauma to its main menu, then exit.
[*]Press Win+R and open:
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\__WORKSHOP_ID__[/code]
[*]Run Install-to-desktop.cmd, or copy BarotraumaModAssistant.exe into your own folder and run it.
[/olist]
If that folder is missing, browse the game's local files in Steam, return to steamapps and check the download library:
[code]workshop\content\602960\__WORKSHOP_ID__[/code]
The desktop copy is in [code]%LOCALAPPDATA%\BarotraumaModAssistant\WorkshopProgram[/code]
[b]After a Workshop update, close the old app and rerun the installer or replace your desktop copy.[/b] Steam does not update that separate copy. Unsubscribing does not remove it or your settings.

[h1]Everyday use[/h1]
[olist]
[*]Close the game and dedicated server before changes. Local inspection is the default. Choose Online inspection or an update explicitly, with Steam signed in.
[*]Update selects items for a task; Enabled controls what the game loads. These are separate. Start the update or review an Auto-sort preview, then apply it explicitly.
[*]Save/import game presets and review missing entries/differences. Subscribe manually in Steam before Download and apply. Install local mods separately.
[*]Save a tested setup as a snapshot; review restore scope before restoring. LuaCs client backups are separate from mod snapshots.
[*]Tools contains LuaCs, detailed analysis, logs, recent error details and reports. Settings offers themes, font size, density and concurrency choices.
[/olist]

[h1]Purpose and limits[/h1]
Steam controls actual download scheduling; parallel requests cannot guarantee bypassing queues, server limits or bandwidth. Accepted downloads may continue after stopping. XML and dependency findings do not prove gameplay compatibility or detect malware. Follow authors' instructions and test in game. Impact describes scope, not quality. Native XML presets do not store versions/hashes or fetch historical versions; legacy JSON and the JSON friend-list export retain recorded information. Snapshots consume space and restore saved files only, not subscriptions, Steam cache or LuaCs.

[b]Access:[/b] the selected game folder, this user's game files, Steam game manifests and app data. Online operations use the official interface for Barotrauma subscription/download status and public item metadata. Steam may show the game as running. No process enumeration, process-memory inspection, automatic subscription changes, wallet/credential/firewall checks, telemetry or administrator elevation.
LuaCs C# mods are not sandboxed; use trusted mods. This desktop app is not an OS sandbox either. Review personal information before sharing logs. [url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]Access details[/url]
