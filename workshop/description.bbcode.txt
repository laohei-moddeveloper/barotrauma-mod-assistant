[h1]BaroDock｜希望下一次下潜前少一点折腾[/h1]
因为自己遇到过更新缓慢、排序不清楚、联机清单不一致的问题，我做了这个工具，希望也能帮到其他玩家。不同电脑和模组会暴露我没有发现的问题。欢迎批评、建议和使用体验，不懂代码也没关系；说清楚想做什么、哪里不顺手就很有帮助。感谢愿意尝试并帮助改进的人。

[b]这是独立 Windows 64 位程序，工坊负责分发文件。请运行单独副本，不用在游戏中启用这个包，也不要设为服务器必需模组。助手本身无需 Python、LuaCs 或 C#。[/b]

[h1]0.7.0：回应社区的访问范围建议[/h1]
旧版为了判断游戏运行状态，读取的进程名称范围过大，确实没有必要。本版删除系统进程遍历和自动订阅调用；启动和重新检测默认只检查本地文件，联网及 LuaCs 安装前说明具体访问内容。感谢指出问题的玩家。

[b]访问范围：[/b]所选游戏目录、当前用户的游戏模组与配置、Steam 安装及工坊清单。修改保护只检查所选游戏目录的两份程序文件是否被占用，不读取其他进程名称或内存。不检查钱包、浏览器凭据、防火墙，不遥测、不自动上传日志或报告，不请求管理员提权。
联网由用户主动选择，通过官方 Steam 接口读取潜渊症订阅和下载状态，公开资料查询会发送模组编号。连接时 Steam 可能显示游戏正在运行。LuaCs 只在确认后下载官方 GitHub 补丁，备份替换客户端文件并开启 C#。
[b]普通桌面程序并非系统沙箱，无法隔离 Steam、LuaCs 或第三方模组的权限。[/b]下载包及设置页含访问说明；[url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]详细用途、原生接口原因和限制[/url]可公开查看。

[h1]安装与首次使用[/h1]
[olist]
[*]订阅并等待 Steam 下载完成；如有需要，先启动游戏到主菜单，让游戏安装工坊内容，再退出。
[*]按 Win+R，打开：
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\__WORKSHOP_ID__[/code]
[*]双击「安装到桌面.cmd」创建 BaroDock 入口；也可以复制 BarotraumaModAssistant.exe 到自己的文件夹运行，无需单独安装运行环境。
[/olist]
找不到上述目录时，在 Steam 右键游戏 → 管理 → 浏览本地文件，返回 steamapps，检查下载所在库的：
[code]workshop\content\602960\__WORKSHOP_ID__[/code]
桌面副本位于 [code]%LOCALAPPDATA%\BarotraumaModAssistant\WorkshopProgram[/code]
[b]工坊更新后：[/b]退出旧助手，再运行安装脚本或覆盖自己复制的程序。Steam 不会自动替换独立桌面副本。保留原程序文件名及设置目录方便升级；取消工坊订阅不会删除桌面副本或助手设置。

[h1]日常操作[/h1]
[olist]
[*]更新、启用切换、保存排序、切换配置、安装 LuaCs 前关闭游戏和服务器。默认本地检测；需要 Steam 状态和公开资料时点击「联网检测」。联网操作需 Steam 登录。
[*]「更新」勾选参与本次任务的项目，「启用」决定游戏是否加载，两者不同。选择后点「开始并行更新」。
[*]「加载顺序」支持自动建议、拖动、上下移动、锁定及前后规则。查看「排序依据」，核对预览后保存。可导入导出本地 JSON 规则，导入本身不修改游戏顺序。
[*]保存多套配置或比对朋友清单；缺失工坊项目需先在 Steam 手动订阅，再「下载并应用」。本地模组需另行安装。
[*]「工具与脚本」提供 LuaCs、快照、日志和报告；右上角可实时切换中文/English。「设置与外观」调整主题、字号、密度、显示列及并发参数。
[/olist]

[h1]功能及实际限制[/h1]
[list]
[*][b]并行请求与安装：[/b]同时提交请求、安装已下载缓存，复用校验过的文件、重试失败项并保存备份。Steam 决定实际网络调度，不能保证同步下载或突破队列、带宽限制；停止助手后已接受的下载可能继续。
[*][b]有依据的排序：[/b]识别资源依赖，使用明确前后规则，尽量保持现有重复定义的覆盖优先级，不按名称或类型猜顺序。参考 RimPy 的规则思路，没有照搬 RimWorld 的加载规则。作者说明优先。
[*][b]静态兼容风险：[/b]比较 XML 定义/Override、可读 Lua 钩子和 C# 补丁，显示关联文件及潜在重叠。不能保证动态脚本、编译代码及游戏内运行兼容，不修复模组源码。「重要程度」表示影响范围，不代表质量。
[*][b]LuaCs 与 C#：[/b]下载匹配的官方 Windows 客户端补丁，校验、备份并安装。恢复仅覆盖助手保存的文件；原有安装可能没有备份，设置备份不能卸载 LuaCs。其他电脑和服务器需单独设置。只使用可信脚本模组；文件检查不是游戏内验证。
[*][b]配置及快照：[/b]保存启用清单、顺序和模组文件。共享清单不能下载历史版本，Steam 提供当前版本；版本/指纹不同默认阻止切换。快照占用磁盘，不恢复订阅或 LuaCs 补丁。
[*][b]缓存与轻量检测：[/b]复用分析，所选游戏文件占用或状态未知时推迟深度扫描；无法识别占用者或另一份安装的运行状态，关闭游戏后重新检测。
[*][b]双语与外观：[/b]三种主题、强调色、字体、列表密度、筛选搜索、右键菜单、快捷键、可选列及窗口记忆；原始模组名、路径与日志保留原语言。
[/list]
