[h1]让模组整理少一点折腾[/h1]
BaroDock 是免费的独立 Windows 64 位潜渊症模组管理工具：排序预览与拖动、模组更新、游戏清单及备份、XML 覆盖对照。无需 Python，界面可切换中文/English。
[b]这是工具分发包，安装到桌面后运行，无需在游戏中启用，也无需服务器安装。[/b]

[h1]安装与首次使用[/h1]
[olist]
[*]订阅，等待 Steam 下载完成；如安装目录还没有生成，启动游戏到主菜单，再退出。
[*]按 Win+R，打开：
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\__WORKSHOP_ID__[/code]
[*]双击「安装到桌面.cmd」，或复制 BarotraumaModAssistant.exe 到自己的文件夹运行。
[/olist]
找不到上述目录：在 Steam 浏览游戏本地文件，返回 steamapps，查看下载所在库的：
[code]workshop\content\602960\__WORKSHOP_ID__[/code]
桌面副本在 [code]%LOCALAPPDATA%\BarotraumaModAssistant\WorkshopProgram[/code]
[b]工坊更新后需退出旧助手，重新运行安装脚本或覆盖桌面程序。[/b]Steam 不会自动替换桌面副本；取消订阅也不会移除副本及设置。

[h1]日常使用[/h1]
[olist]
[*]先关闭游戏和服务器。默认本地检测；「联网检测」和更新需你主动选择，并保持 Steam 登录。
[*]「更新」勾选参与任务的项目，「启用」决定游戏加载，两者独立。点「开始并行更新」，或先预览排序再确认应用。
[*]配置窗口保存/导入游戏清单，查看缺项和差异。缺失工坊项目在 Steam 手动订阅后再「下载并应用」；本地包另行安装。
[*]保存经过验证的快照；需要时先检查恢复范围。LuaCs 客户端备份与模组快照独立。
[*]工具页有 LuaCs、XML 分析、日志、错误详情和报告；设置页有主题、字号、密度与并发参数。
[/olist]

[h1]用途与限制，请先了解[/h1]
Steam 决定实际下载调度，不能保证突破队列、服务器或带宽限制；已接受的下载可能在停止任务后继续。静态 XML 和依赖提示不证明游戏内兼容，也不检测恶意代码；作者说明和实测优先。「影响范围」不是质量评分。游戏 XML 清单不含版本/指纹，不能获得历史版本；旧 JSON 和导出的联机 JSON 保留其已记录信息。快照占用空间，只恢复保存过的文件，不改变订阅、Steam 缓存或 LuaCs。

[b]访问范围：[/b]所选游戏目录、当前用户游戏文件、Steam 游戏清单及助手数据；联网通过官方接口查询潜渊症订阅/下载与公开项目资料。Steam 可能显示游戏正在运行。无进程遍历、进程内存读取、自动订阅/退订、钱包/凭据/防火墙检查、遥测或管理员提权。
LuaCs 的 C# 模组没有沙箱，请只使用可信模组；普通桌面程序也不是系统沙箱。分享日志前检查个人信息。[url=https://github.com/laohei-moddeveloper/barotrauma-mod-assistant/blob/main/ACCESS_AND_PRIVACY.md]详细访问说明[/url]
