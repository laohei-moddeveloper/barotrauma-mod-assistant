[h1]让下一次下潜，少一点等待[/h1]
打开游戏先等一堆模组更新，加载顺序越排越乱，和朋友联机时清单又对不上？这个助手把更新、排序、配置与脚本安装放到一个窗口里，让常用操作更好找。

[b]这是 Windows 64 位的独立管理程序，工坊负责分发文件。订阅后手动启动助手即可，无需在游戏中启用这个包，也不要把它列为服务器的必需模组。[/b]
助手本身无需 Python、LuaCs 或 C# 环境；需要脚本的游戏模组可以使用助手的一键安装功能。

[h1]订阅后怎么用：三步开始[/h1]
[olist]
[*]订阅本项目，等待 Steam 完成下载。首次可启动《潜渊症》到主菜单，等待工坊安装完成，再退出游戏。
[*]按 Win+R，粘贴下面的路径并回车，打开本项目的安装目录：
[code]%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed\3812360206[/code]
[*]双击「安装到桌面.cmd」，它只把助手复制到你的个人程序目录，并创建「潜渊症模组更新助手（工坊版）」桌面快捷方式。以后从桌面启动即可。也可以手动将 BarotraumaModAssistant.exe 复制到自己的文件夹后双击运行。
[/olist]
没有找到上述目录？在 Steam 库里右键《潜渊症》→ 管理 → 浏览本地文件，从游戏目录向上两级到 steamapps，再进入：
[code]workshop\content\602960\3812360206[/code]
这个目录是 Steam 下载缓存；下载完成后同样能找到「安装到桌面.cmd」。不同 Steam 库请查看实际下载所在的库。

[b]更新工坊里的助手后，请先退出旧助手，再运行一次「安装到桌面.cmd」，替换桌面入口所使用的程序。桌面版是独立副本，卸载工坊包不会自动删除它。[/b]

[h1]日常使用：选模组 → 更新 → 开始下潜[/h1]
[olist]
[*]保持 Steam 登录；更新文件、修改启用状态、切换配置、保存排序或安装 LuaCs 前，关闭游戏及专用服务器。
[*]等待助手检测已有模组。列表左侧「更新」勾选决定本次更新目标，「启用」决定下次游戏加载，两者是独立操作。
[*]点击上方「开始并行更新」。默认同时提交 4 项更新请求、同时安装 3 项，可在「设置与外观」调整。
[*]需要调整顺序时，点击「加载顺序」，使用「自动排序」生成建议，或拖动/上下移，核对预览后点击「保存加载顺序」。
[*]完成后点击「启动游戏」。LuaCs、诊断、缓存同步和报告放在「工具与脚本」；右上角「外观设置」可立即换肤。
[/olist]

[h1]你能用它做什么[/h1]
[list]
[*][b]并行更新与缓存复用[/b]：同时向 Steam 提交多个工坊请求，完成下载的模组进入并行安装队列；未变化的已校验文件直接复用，失败项可以重试，保留安装备份。
[*][b]逐项启用与加载排序[/b]：管理工坊和本地模组的启用状态；查看实际加载顺序、拖动调整、自动建议，并支持自定义前后规则与位置锁定。
[*][b]兼容风险有依据[/b]：比较 XML 标识、Override、可读取的 Lua 钩子及 C# 方法补丁，区分与已启用模组的当前重叠和未启用组合的潜在风险，显示相关文件与建议。
[*][b]LuaCs + 永久 C# 一键设置[/b]：从 LuaCs 官方发布取得匹配版本的 Windows 客户端补丁，校验、备份并安装；支持永久开启 C#、恢复安装前文件和安装后验证指引。
[*][b]多套配置与联机配齐[/b]：保存核心包、启用清单及实际顺序，切换单人/联机组合；导入朋友清单，核对后订阅下载缺少的工坊项目。
[*][b]整套快照与问题排查[/b]：更新前保存独立文件快照，恢复保存过的组合；读取游戏/LuaCs 日志，导出更新、兼容和联机清单。备份会占用磁盘空间。
[*][b]检测更省重复工作[/b]：缓存未变化的分析，游玩时默认使用轻量检测并延后深度扫描；关闭游戏后再刷新完整结论。
[*][b]外观按习惯调整[/b]：深海蓝、石墨灰、明亮三种主题，自选强调色、字号和列表疏密；筛选、右键菜单、快捷键、显示列和折叠任务记录，记住窗口大小与列宽。
[/list]

[h1]常见问题[/h1]
[b]订阅之后怎么没有游戏内按钮？[/b]
这是独立工具，订阅完成后按上方步骤创建桌面入口；启用这个工坊包不会自动运行程序，也不会给游戏增加按钮。

[b]是不是一定能让所有下载同时变快？[/b]
助手可以并行提交请求、并行安装并复用缓存，但实际网络下载由 Steam 调度，不能保证突破客户端队列、服务器限速或带宽限制。停止助手后，Steam 已接受的下载也可能继续。

[b]“高兼容”是不是保证不会冲突？自动排序是不是一定正确？[/b]
兼容等级和排序都是静态分析建议。“重要程度”表示内容影响范围，不是质量评分。动态脚本、二进制代码和游戏运行时行为无法全部静态判断；作者说明、实际游戏与联机测试优先。助手不会自动修复模组代码冲突。

[b]LuaCs 安装按钮对谁生效？[/b]
只处理本机 Windows 客户端。补丁版本不匹配时会停止；其他电脑、独立服务器需分别配置。开启的是 C# 脚本，建议使用可信来源的脚本模组。磁盘检测正常不等于游戏内脚本已实测成功。

[b]联机配齐能自动下载清单里的旧版本吗？[/b]
Steam 只提供当前工坊版本，不能按朋友清单取得历史版本。默认遇到版本或指纹差异时不切换配置；本地模组需要自行安装。快照只能恢复曾保存的文件，不恢复 Steam 订阅状态或 LuaCs 客户端补丁。

[b]为什么 Steam 有时显示《潜渊症》正在运行，却没有游戏窗口？[/b]
助手使用游戏的 Steam 工坊接口，因此 Steam 可能把这次连接显示为游戏运行状态；这不表示助手已打开游戏窗口。
