# 访问范围与权限

## 实际行为

- 客户端插件；三个 Harmony 补丁仅作用于原版事件编辑器的 CreateGUI、AddToGUIUpdateList 与 Update。工作区打开时暂停底层节点图输入与 GUI，关闭后恢复。
- 插件注册自己的控制台命令和入口按钮，卸载时撤销自己的补丁、命令及缓存。
- 从当前游戏程序集读取 Action 类型和 Serialize 元数据。不会实例化导入的 Action 或执行导入事件。
- 指定文件导入最多 8 MiB；XML 禁止 DTD 与外部实体，XmlResolver 为空。
- 导出只使用自己的 `%LOCALAPPDATA%/BaroEditor/Exports`；高级覆盖只针对用户显式导入的文件，并先备份、检测外部修改。
- 剪贴板只写入用户选择复制的 XML，不读取剪贴板。
- 无网络、遥测、进程启动、注册表操作、管理员请求、目录扫描、服务器补丁或战役运行时 Action 补丁。

## C# 宿主的边界

LuaCs 的 C# 插件运行于游戏进程，不提供本工具可独立声明的操作系统权限沙箱。游戏账号拥有的文件访问权，理论上也是受信任 C# 代码的能力。`IgnoresAccessChecksTo` 用于访问游戏内部事件编辑器 API；它不是 Windows 提权，但说明本工具需要受信任的客户端代码环境。

发布包不设置 LuaCs 的 C# 全局策略、不修改真实游戏 DLL、不附带自动启动脚本。是否允许 C# 模组由用户在 LuaCs 中自行决定。

原版目录、DLC 与工坊缓存的路径检查降低误覆盖风险，不应被当作安全沙箱：路径别名、链接及外部程序不受它约束。先备份和两次源文件哈希检测能发现通常的外部编辑，但与不配合的外部写入程序之间没有全局事务锁。原文件的 BOM、编码和格式可能在显式覆盖时改变；备份保留覆盖前原始字节。

## 开发工具与正式包

`prepare_game_test.ps1` 创建独立测试目录、复制程序和 LuaCs 配置、引用游戏 Content，并在复制的 LuaCs 配置中允许 C# 测试代码。`auto_test_boot.ps1` 仅修改这份测试程序以跳过启动等待，并在主菜单请求一次 LuaCs 重载。它们不是运行所需文件，不会进入工坊包。

测试目录中引用的游戏资源也不是操作系统强制只读；测试代码不写这些资源。不要自行在测试目录编辑引用的 Content 或 DLC。
