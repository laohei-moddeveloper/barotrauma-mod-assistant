
工具要求新目录，保留真实游戏配置和程序。它复制测试模组并加入开发专用 GameValidation.cs；输出截图和 JSON 到测试运行目录。启动测试客户端前应先确保 Steam 客户端已就绪。执行游戏内测试仍需单独启动复制的客户端；上述准备命令本身不启动游戏。
