# 更新记录

## 0.1.1 — 汉化与搜索

- 原版 66 个动作及其序列化属性增加中文显示名；XML 名称保留，可用中英文搜索。
- 事件树、属性面板、添加动作、添加属性、文件事件选择和游戏事件载入增加搜索。
- 搜索支持多个关键词，保留父级上下文，限制结果组件数量；180 ms 延迟过滤，XML 索引按修改版本缓存。
- 事件选择直接线性遍历节点，避免宽文件反复查找节点；撤销重做尽量保留编辑位置。
- 剪贴板输出和子树 XML 编辑增加换行缩进，保留混合文本、CDATA、xml:space 和对话内换行。
- 不增加网络访问、文件扫描或宿主权限。

## 0.1.0 — 预览版

- 原版事件 XML 树、通用 Action 属性及子树 XML 编辑。
- 文件导入、游戏已加载事件导入和原版节点图对接。
- 连续对话批量编辑，保留现有分支和效果。
- 有界撤销重做、默认导出副本、显式剪贴板输出。
- 单独确认的本地源文件覆盖、原始字节备份及外部变化检测。
- 按需 Action 元数据缓存及线性事件列表遍历。
- 中文与英文 UI；无联网、遥测或运行时事件行为补丁。

- 更名为 BaroEditor|潜渊症通用事件编辑器；兼容旧控制台命令。
- 深色独立工作区、卡片事件树、单一子窗口管理，编辑时隔离底层节点图输入。

基础游戏界面和 Action 元数据检查通过；复杂事件行为与完整节点图往返仍需进一步验证。
