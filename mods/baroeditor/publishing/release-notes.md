BaroEditor|潜渊症通用事件编辑器 0.1.0 预览版。

导入已有原版事件，使用 XML 树、Action 属性和子树编辑；连续对话每行一句，保留已有分支与效果。默认导出副本，另有显式剪贴板输出及带备份的本地覆盖。

离线编译零诊断、273 项核心检查通过。原版 9 个 XML 文件、226 个事件的语义往返一致；本机元数据核对 66 个 Action、313 个属性。

新版使用独立的深色工作区、卡片事件树和单一子窗口管理；打开编辑器会收起控制台。旧命令仍可使用，推荐 `baroeditor` / `beditor`。

基础游戏界面、批量对话窗口和原版 Action 元数据检查通过。**此为预览版，复杂事件运行、完整节点图往返和所有分辨率的交互尚未充分验证。**

运行包需要客户端 LuaCs 与 C# 支持，不包含游戏 DLL 或开发测试启动工具。使用与访问范围见 README。
